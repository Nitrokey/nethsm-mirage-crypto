# nethsm-crypto - Cryptographic primitives for NetHSM

nethsm-crypto is a cryptographic library for algorithms that
[mirage-crypto-ec](https://github.com/mirage/mirage-crypto) doesn't provide,
that is currently SECP256K1 (the "Bitcoin curve") and the Brainpool curves.
Additionally it offers alternative implementations of the "NIST curves" P256,
P384 and P521. It is originally based on `mirage-crypto-ec`, but heavily
modified in order to use code generated by
[ECCKiila](https://gitlab.com/nisec/ecckiila).

Most of the critical code is generated:
- The field operations (base field and scalar
field) are generated by [fiat-crypto](https://github.com/mit-plv/fiat-crypto).
- The point operations are generated by
  [ECCKiila](https://gitlab.com/nisec/ecckiila).

The ECDH and ECDSA implementations are copied from `mirage-crypto-ec`. A lot of
other code is copied or based on `mirage-crypto-ec`.

The Schnorr signature for
[BIP-340](https://github.com/bitcoin/bips/blob/master/bip-0340.mediawiki) is
handwritten based on the reference implementation.

## Build

```bash
dune build
dune runtest
```
